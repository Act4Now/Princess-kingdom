# Princess Kingdom V52

## Changes
- Moved the active-player indicator into the same scoreboard panel position used by Team Mode. With multiple profiles, the active player is visible in that location. When Team Mode is active, the panel displays both the active player and the team scoreboard.
- Replaced the Team Mode skip action label with **„Nu am reușit”** (English: **“I couldn’t do it”**).
- In Team Mode, pressing **„Nu am reușit”** rotates the active team and loads the next challenge without adding a star/point to the team that did not complete the challenge.
- Preserved existing profile IDs, saved progress, game modes, and Princess artwork references.

## Artwork
Princess image files are intentionally not included. Keep the existing V50/V51 `princess-*.webp`, `princess-*.svg`, and `princess-fallback.svg` assets in the project.
